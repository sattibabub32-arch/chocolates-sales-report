# 📊 Sales Analytics Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Sales Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard provides a clear view of sales performance, profit, shipment distribution, products, sales persons, and geographical sales. It also allows users to analyze the data based on different date ranges.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Track total sales amount and profit
- Compare Current Year (CY) with Previous Year (PY)
- Analyze shipment distribution
- Identify top-performing products
- Identify top-performing sales persons
- Analyze sales by geographical region
- Monitor important business KPIs
- Provide an interactive and easy-to-understand dashboard

---

## 📊 Dashboard Features

### 🔹 KPI Cards

The dashboard displays important KPIs such as:

- Total Boxes
- Total Amount
- Total Cost
- Total Profit
- Profit Ratio

### 🔹 Amount – CY vs PY

A line chart is used to compare the current year's sales amount with the previous year's sales amount.

### 🔹 Boxes – CY vs PY

This visualization compares the number of boxes sold between the current year and previous year.

### 🔹 Shipment Distribution

A distribution chart shows how shipments are distributed across different quantities.

### 🔹 Amount by Geography

A donut chart represents sales distribution across different geographical regions.

### 🔹 Top 5 Sales Persons

The dashboard identifies the top-performing sales persons based on:

- Total Amount
- Total Boxes
- Profit %

### 🔹 Top 5 Products

A visual comparison of the top-performing products based on sales amount.

### 🔹 Product Analysis

A detailed table provides product-level information including:

- Product
- Total Amount
- Total Profit %
- Total Profit

### 🔹 Date Filter

Users can select a specific date range using the calendar/date slicer to dynamically analyze the dashboard.

## 🧮 DAX

DAX (Data Analysis Expressions) was used to create calculated measures and KPIs for the dashboard.

Examples of calculations include:

- Total Sales
- Total Cost
- Total Profit
- Profit %
- Current Year Sales
- Previous Year Sales
- Year-over-Year Analysis

## 📈 Key Insights

The dashboard helps users quickly identify:

- Overall sales and profit performance
- Growth or decline compared with the previous year
- Best-performing products
- Top sales persons
- Regional sales contribution
- Shipment distribution
- Profitability trends
